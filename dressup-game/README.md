## 🎨 如何制作素材

### 方法1：网上找图 + Photopea 处理

1. 找到你想要的素材图（发型、衣服等）
2. 打开 **Photopea.com**（免费在线PS）
3. 新建画布：1333 x 2000 像素，**透明背景**
4. 将素材拖入，调整位置和大小，对齐到底图对应位置
5. 导出为 PNG

### 方法2：直接在底图上覆盖

1. 在 Photopea 中打开你的 base.png 作为参考
2. 新建透明图层
3. 把找到的素材放到对应位置
4. 隐藏底图图层，只导出素材图层

## 📐 各素材的放置位置指南

| 素材类型 | X 位置（居中） | Y 位置 | 建议尺寸 |
|---------|---------------|--------|---------|
| 发型 | 居中 (约 667) | 0 - 400 | 宽度 800-1000 |
| 服装 | 居中 (约 667) | 280 - 1200 | 宽度 600-900 |
| 鞋子 | 居中 (约 667) | 1750 - 2000 | 宽度 400-500 |
| 项链 | 居中 (约 667) | 300 - 400 | 宽度 300-400 |
| 手环 | 左侧 (约 200) | 750 - 850 | 宽度 100-150 |

---

## ⚠️ 重要注意事项

1. **所有图片必须是 1333x2000 像素**（和底图一样）
2. **必须是透明背景 PNG**
3. **文件名必须完全匹配**（hair1.png, outfit1.png 等）
4. **素材位置要和底图对齐**
